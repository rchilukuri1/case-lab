# Consulting Club Case Lab

A free, self-serve case-interview training platform built for members of the **Consulting Club at Georgia State University (CCG)**. It takes a complete beginner from "what is a case?" to practicing full cases on their own.

**Live site:** https://rchilukuri1.github.io/case-lab/

![Case Lab home page](screenshot-home.png)

## What's inside

- **10 short, visual lessons** covering the full case flow: clarifying, structuring, analysis, math, and recommendations
- **8 casebook-style practice cases** (profitability, market entry, pricing, M&A, operations) with charts and data exhibits
- **Case generator** that creates new practice cases across 5 case types and 8 industries, with reproducible case codes
- **Written-answer feedback** that checks structure, key insights, and recommendations
- **Math drills**, a **reference library** (case types, frameworks, finance formulas, glossary), and a **4-week study plan**

![A practice case with guided tips](screenshot-case.png)

## Built with

HTML, CSS, and vanilla JavaScript in a single file, with custom SVG charts (waterfall, break-even, trend) and no frameworks or backend. Progress is saved in the browser. Built with the help of Claude (Anthropic).

## Notes

- Everything runs in the browser; no account or data collection.
- AI coaching features work only when the page is opened inside Claude. On this site, written answers use the built-in feedback.

Built by Ravi Chilukuri for CCG at Georgia State University.
